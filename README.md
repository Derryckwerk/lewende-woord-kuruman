# Lewende Woord Kuruman

Custom WordPress theme (`lewendewoord`) for Lewende Woord Kuruman. Plain HTML, CSS and JavaScript with a small amount of PHP.

Only the theme is tracked in this repository. WordPress core, plugins, uploads and `wp-config.php` are not.

- Theme: `wp-content/themes/lewendewoord/`
- Pages are WordPress pages with these slugs: `wie-is-ons`, `die-span`, `lidmaatskap`, `bydrae`, `kontak-ons`, `komende-gebeure`, `bedieninge`
- Slideshow and advert images come from FileBird folders: "Home page slideshow", "Lidmaatskap page slideshow", "Komende gebeure page"
